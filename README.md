# SOX 공포·탐욕 지수 대시보드

필라델피아 반도체지수(SOX)에 CNN Fear & Greed Index 방법론을 적용한 대시보드.
GitHub Pages로 무료 호스팅되며, GitHub Actions가 평일마다 자동으로 데이터를 갱신합니다
(내 컴퓨터가 꺼져 있어도 동작).

## 자세한 설치·유지보수 안내는 대시보드 하단 "산출 방법"과 update_data.py 주석 참고.

- 구성종목 변경 시: update_data.py 상단의 CONSTITUENTS 목록 수정 (https://www.nasdaq.com/docs/SOX)
- 본 지표는 참고용이며 투자 판단의 근거가 아님.
